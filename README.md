# MuseCanvas

MuseCanvas 是一款 AI 创作画布，用来整理素材、生成图片和视频，以及撰写剧本。

本项目不提供源码。

## 下载与安装

系统要求：搭载 Apple 芯片的 Mac，macOS 13.5 或更高版本，已安装 Chrome 或 Edge。

1. 打开 [GitHub Releases](https://github.com/hou361996193-cloud/Musecanvas/releases)，在对应版本的附件中下载安装 ZIP。
2. 完整解压后，双击「双击安装.command」，按提示安装。
3. 安装完成后，双击桌面的 MuseCanvas 图标启动。

## 软件更新

接入本仓库更新渠道的 MuseCanvas 会在打开时检查 GitHub Releases。发现新版后，软件会弹出「发现新版本」，显示版本号、更新内容和下载入口。
