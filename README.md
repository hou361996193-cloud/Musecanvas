# MuseCanvas

MuseCanvas 是一款在本机运行的 AI 创作画布，可用来整理素材、生成图片和视频，以及撰写剧本。

## 下载

当前版本为 **0.23.3**。使用前请先安装 Chrome 或 Edge。

| 平台 | 系统要求 | 安装包 |
| --- | --- | --- |
| macOS | Apple 芯片，macOS 13.5 或更高版本 | [下载 macOS arm64 版](https://github.com/hou361996193-cloud/Musecanvas/releases/download/v0.23.3/MuseCanvas-0.23.3-mac-arm64.zip) |
| Windows | Windows x64 | [下载 Windows x64 版](https://github.com/hou361996193-cloud/Musecanvas/releases/download/v0.23.3/MuseCanvas-0.23.3-win-x64.zip) |

更新说明和两份 ZIP 的 SHA-256 校验文件见[发布页](https://github.com/hou361996193-cloud/Musecanvas/releases)。

## 安装与启动

### macOS

1. 完整解压 ZIP，双击 `双击安装.command`，按提示确认。
2. 如 macOS 阻止打开，请进入「系统设置 → 隐私与安全性」选择「仍要打开」。请先确认压缩包来自本仓库的发布页。
3. 安装完成后，从桌面打开 MuseCanvas。默认数据目录为 `~/Library/Application Support/MuseCanvas/data`。

### Windows

1. 将 ZIP 完整解压到当前用户可写的文件夹，例如 `D:\MuseCanvas`。
2. 首次双击 `Install.cmd` 校验安装包。
3. 双击 `MuseCanvas.cmd` 启动。默认数据目录为 `%LOCALAPPDATA%\MuseCanvas\data`。
